## Knowledge

- [Anthropic Engineering: "Effective context engineering for AI agents"](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Defines context, context rot, compaction, structured note-taking and just-in-time retrieval. Use for: what to keep in context, what to save outside it, how to find the right page in a long manual.
- [Claude Platform Docs: "Context windows"](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, how it grows turn by turn, what happens on overflow, compaction and context editing. Use for: context size and cost questions.
