Context and memory in an agent

LayerWhat it isLivesCost
Context windowAll text the model gets on one call, plus its replyOne callTokens sent on every call
HistoryMessages and tool results the program resendsOne sessionGrows each step
NotesFacts saved to files and loaded next sessionAcross sessionsOnly the tokens loaded
RetrievalSearch over chunks; best few pasted inOutside the windowOnly the chunks pasted in

Decision steps

  • Total input tokens = the sum of every call's input; each call is sent the whole history.
  • Drop or clear tool results the task no longer needs.
  • Save soft facts (preferences, progress) as notes; look up hard facts (bookings, training status) with a tool.
  • Corpus under about 200,000 tokens: consider putting it all in the prompt, with caching. Larger: retrieve.
  • Manuals with codes and part numbers: exact-match (BM25) plus embeddings.
