# Resources

## Knowledge

- [Effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Covers context as a finite resource, context rot, compaction, structured note-taking and just-in-time retrieval. Use for: lessons on context windows and agent memory.
- [Building effective agents](https://www.anthropic.com/engineering/building-effective-agents)
  Covers the augmented LLM (retrieval, tools, memory), workflows versus agents and stopping conditions. Use for: agent architecture, retrieval basics and workflow-versus-agent choices.
