# Resources

- [Effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context, context rot, compaction, structured notes, just-in-time retrieval and sub-agents. Use for: explaining what an agent keeps in context and how it remembers.

  How the window accumulates turns, what counts toward it, and how to manage it. Use for: token and cost questions about context growth.
