Context and memory in an agent

From lesson 1.

What is in the context window

  • System prompt
  • Tool definitions
  • Messages so far
  • Tool results

Rules

  • The model keeps nothing between calls; the program resends the history each call.
  • A long tool result is input again on every later call.
  • A new session starts without the old history.

Where does an item go?

  • Every step needs it: system prompt, in context.
  • Only some steps need it, and it already exists: retrieve it with a tool.
  • It must outlive the session: save it as a note and reload it.
  • The window is nearly full: compact it into a summary.

Sources: Context windows, Effective context engineering.
