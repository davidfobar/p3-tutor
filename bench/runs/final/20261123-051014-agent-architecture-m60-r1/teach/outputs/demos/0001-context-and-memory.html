Demo: run a booking request and watch the context fill

A student asks: “Book the laser cutter for Friday at 2 pm.” Each press of Run next step is one call to the model, then the program runs the tool the model asked for. Every token count here is a made-up example.

Predict, then try:

  1. Run two steps. Before call 3, guess: does it send only the 400 tokens the last step added, or the whole history? Run it and compare.
  2. Run all five steps and note the total sent. Start over, run three steps, clear old tool results, then finish. How far does the total fall?
  3. Run two steps, then clear. Which result is gone from the bar? Run step 3 and compare the “sent” number with a run where you did not clear.
