Facts to keep

  • The window holds the system prompt, tool definitions, all messages, tool results and the reply (Context windows).
  • Every call re-sends the whole history: tokens sent = sum over calls, not the final size.
  • More tokens can mean worse recall: context rot.
  • Free space by clearing old tool results (lightest) or compaction (summary, lossy) (Effective context engineering).
  • A new session starts with an empty window; only saved notes carry over, and the model does not change.
  • Retrieval: chunks of a few hundred tokens, embeddings plus BM25, rerank (example: 150 then top 20). Under about 200,000 tokens you can skip it (Introducing Contextual Retrieval).

Test for a note

  1. Will it still be true next week?
  2. Would a future session act differently because of it?
  3. Is it a fact (one line) or a record (fetch it by a tool)?

Cost method

Tokens per call, times the calls that carry it, times requests per day.
