# Resources

## Knowledge

- [Effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Context rot, compaction, note-taking memory, just-in-time retrieval and sub-agents. Use for: explaining what an agent keeps in context and saves outside it.
- [Context windows](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  How tokens accumulate across turns, what counts toward the window, and how it is managed. Use for: facts on context size, cost and overflow.
- [Introducing Contextual Retrieval](https://www.anthropic.com/news/contextual-retrieval)
  Chunking, embeddings plus keyword search, reranking, and when to skip retrieval. Use for: how an assistant finds the right page in a long manual.
