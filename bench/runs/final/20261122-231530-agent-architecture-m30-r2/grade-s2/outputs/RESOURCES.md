# Agent architecture Resources

## Knowledge

- [Article: "Building effective agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/building-effective-agents)
  Primary-source overview of agents versus workflows. Use for: what an agent is (the "Agents" section: tools used in a loop on environmental feedback, with stopping conditions such as a maximum number of iterations), when to use an agent at all, and tool design ("Appendix 2: Prompt engineering your tools").
- [Docs: "Define tools" (Claude Platform docs)](https://platform.claude.com/docs/en/agents-and-tools/tool-use/define-tools)
  Official tool-use documentation. Use for: what a tool definition holds (name, description, input schema), how the model picks a tool from the descriptions ("Best practices for tool definitions"), and what the model outputs when it uses a tool ("Model responses with tools").
