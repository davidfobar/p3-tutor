# Agent architecture Resources

## Knowledge

- [Doc: "How tool use works" (Claude Platform docs)](https://platform.claude.com/docs/agents-and-tools/tool-use/how-tool-use-works)
  Official explanation of the tool-use contract: the model emits a structured tool request, your program runs the tool and sends the result back, and the loop repeats until a stop condition. Use for: who runs a tool, the agentic loop, how a loop ends.
