Context and memory in an agent

From lesson 1. Objective O3.

Key terms

TermMeaning
ContextAll the tokens the model reads in one call: system prompt, tool descriptions, messages, tool results.
Context windowThe limit on the context, counting the model's own output too.
Context rotAccuracy and recall fall as the token count grows.
Tool result clearingRemove old, bulky tool results from the history.
CompactionSummarise a long conversation and restart with the summary.
Notes (memory)Information saved outside the context and read back later. The program runs the reads and writes.
RetrievalFetching only the relevant pieces of a large text into the context, when needed.

Where does a fact go?

FactHome
Short, needed on every request, same for allSystem prompt (context)
About one user, needed in a later sessionNotes, read at session start
Large, shared, needed only for some questionsRetrieval through a tool
Fast-changing, such as a bookingFetch by tool each time; do not save

Rules of thumb

  • The model keeps nothing between calls; the program decides what is re-sent.
  • Each call re-reads the whole context, so early big results are paid for again at every later step.
  • A bigger window gives room, not a reason to fill it.
  • Return less from tools first; then clear; then compact.
  • Notes only help if the program reads them back at the start.
