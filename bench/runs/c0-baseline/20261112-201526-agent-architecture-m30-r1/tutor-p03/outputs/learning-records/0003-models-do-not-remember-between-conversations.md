# A language model does not remember earlier conversations on its own

The learner believed a model automatically remembers what each student said in earlier conversations. This was corrected in chat: the model only sees the text sent in the current request, so anything from last week has to be saved by the app and put back into the context.
Later lessons on context and memory can start from this. Whether the learner can now explain it themselves is not yet shown.

**Evidence:** chat message at the start of the context-and-memory topic.
**Implications:** teach "context window" and "memory as saved notes the app reloads" next; check with a retrieval question.
