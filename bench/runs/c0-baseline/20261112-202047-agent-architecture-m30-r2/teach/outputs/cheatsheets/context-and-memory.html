Rules

  • The model sees only its context and keeps nothing between calls.
  • Each call re-sends the whole list: tokens read = the sum of every call's input.
  • Call n input = call n-1 input + the model's request + the tool's result.
  • A bigger window raises the limit, not the quality or the cost.
  • Return a few relevant chunks, not whole documents.
  • Notes: short, specific, dated, correctable.
