One call

import anthropic
client = anthropic.Anthropic()          # reads ANTHROPIC_API_KEY

reply = client.messages.create(
    model="claude-haiku-5-5",           # any id from the Models overview
    max_tokens=1000,                    # a ceiling, not a target
    messages=[{"role": "user", "content": "Your question"}],
)
text = "".join(b.text for b in reply.content if b.type == "text")

The reply

FieldWhat it holds
contenta list of blocks; take .text from those with type == "text"
stop_reason"end_turn": finished on its own; "max_tokens": cut off at the ceiling

Source: Using the Messages API, “Basic request and response”.

Keep a conversation going

  • The API is stateless: send the full history on every call.
  • After each reply: append {"role": "assistant", "content": text}.
  • Then append the next {"role": "user", ...} and call again with the whole list.
  • Turns alternate user, assistant, user; the list grows by two per exchange.
  • Standing instructions go in the top-level system= parameter, not in the list.

Sources: Using the Messages API, “Multiple conversational turns”; Messages API reference; Models overview.
