# Mission set: using AI agents for learning and research

The learner wants to understand AI agents in order to use them well for common learning and research tasks, not to build agents from scratch.
Lessons should be about using and checking agents on real research tasks, with building only where it shows how they work.

**Evidence:** stated by the learner in chat on 2026-11-13 when asked why they want to learn about agents; see `MISSION.md`.
