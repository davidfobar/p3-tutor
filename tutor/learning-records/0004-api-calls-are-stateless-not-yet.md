# Does not yet see that each model call stands alone

On the diagnostic quiz the learner chose an option that has the server link two calls through the shared API key (M1), so they do not yet know that the Messages API keeps no memory and the program must resend the conversation on every call.
This sits under everything they want to build, so the first lesson (O1, one model call from code) should have them resend the history themselves and see what happens when they leave it out.

**Evidence:** quiz 0001, submission s1, item q1.
