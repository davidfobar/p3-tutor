# Mission: Building AI agents for learning and research

## Why
Write my own AI agents that handle common learning and research tasks, such as finding sources on a topic, reading them and reporting back with citations, so I can build tools that fit how I actually work instead of only using someone else's.

## Success looks like
- Write a program that calls a language model and uses its reply.
- Give the model a tool, run the tool when the model asks for it, and send back the result.
- Write the agent loop myself, with a stop condition, so the agent works through a multi-step task on its own.
- Build a small research agent that searches, reads and cites, and check that its citations hold up.
- Decide when a fixed workflow is the better build than a full agent.

## Constraints
- Learns hands-on first, with the big picture before the details; car examples land best (see `PREFERENCES.md`).
- A first-year engineering student, so time is shared with coursework. Programming background not yet known.

## Out of scope
- The math inside the models (training, transformers).
- Production concerns such as deployment, scaling and security hardening, for now.
